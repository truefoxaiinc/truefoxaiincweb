## Evidence status

- **Evidence-backed:** branded demand for “truefox” and “truefox ai”; current page-level visibility for the homepage, Services, About, Products, Contact, AI Smart Security, Private AI Assistants, Agentic Automation, Request Quote and Case Studies.
- **Experimental:** Kochi company/development terms. The export includes small samples for “ai companies in kochi”, “kochi ai” and “ai company in kochi”; these are directional only.
- **Target:** service and capability topics in the table above where visible page content already supports the intent.
- **Insufficient data:** Kitchener-specific queries and most recently published service pages. Do not infer rankings from metadata or tiny impression counts.

The available standard Search Console export reports query and page dimensions separately. It cannot prove which query produced impressions for which landing page, so cross-page ownership remains a planned targeting model until a joined Search Console API or Looker Studio export is available.
